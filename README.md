# CKYC Bulk Upload Utility

An Excel-based utility developed to streamline and standardize the preparation of CKYC bulk upload files.

## 📌 Project Overview

This utility was developed as a compliance process-automation initiative to simplify the preparation of CKYC bulk upload data and reduce repetitive manual processing.

The utility provides a structured workflow for capturing, validating and preparing CKYC-related information for bulk upload.

## ⚙️ Key Features

- Structured applicant/customer data capture
- Identity information management
- Related person information
- Image/document reference handling
- Master/reference data management
- Data validation
- Structured input processing
- Automated text-file construction
- Standardized output preparation

## 🎯 Objective

The primary objective of this utility is to improve:

- Processing efficiency
- Data consistency
- Data validation
- Accuracy
- Standardization
- Reduction of repetitive manual work

## 🛠️ Technology

- Microsoft Excel
- Excel formulas
- Data Validation
- Structured Templates
- Process Automation
